# 漆黑桌宠

Windows 桌面上的小型渡鸦伙伴，性格取自 DND 冒险中的“漆黑”。

## 启动

双击 `启动漆黑.bat`。依赖 Python 3 和 Pillow：

```powershell
python -m pip install pillow
```

## 操作

- 单击：与漆黑互动。
- 双击或右键选择“出去飞一圈”：飞往桌面上的随机位置。
- 按住左键拖动：移动漆黑，位置会自动保存。
- 右键 → 切换外观：在像素版和写实版之间即时切换。
- 右键还可让漆黑说话、暂停碎碎念或退出。

桌宠窗口约 112 像素，透明、置顶且完全离线。像素版和写实版各自包含待机呼吸、眨眼、歪头及六帧连续振翅动画；后续可继续添加起飞、落地、说话和情绪发光动画。
