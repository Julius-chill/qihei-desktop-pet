# 漆黑桌宠

Windows 桌面上的红眼渡鸦伙伴，性格与故事取自原创 D&D 5e 长篇战役《鸦影》。

## 启动

双击 `启动漆黑.bat`。需要 Python 3 和 Pillow：

```powershell
python -m pip install pillow
```

## 基础互动

- 单击：选中漆黑；按住左键可拖动。
- 双击或右键选择“出去飞一圈”：飞往桌面上的随机位置。
- 按住左键拖动：移动漆黑，位置会自动保存。
- 右键 → 切换外观：像素版和写实版即时切换。
- 可暂停活动、暂停碎碎念、隐藏五分钟，或让漆黑在鼠标附近巡航。
- 右键可让漆黑休息/醒来、查看精力与默契。
- “专注计时”提供 5–90 分钟的桌面专注哨。
- “打开 Geek”会直接启动 `C:\Users\63045\Desktop\LST工作\geek\geek.exe`。

## 动画

- 像素版 v2 使用六帧待机和八帧完整振翅循环；写实版仍可随时切换。
- 像素素材按整数邻近采样缩放，保留硬边和小尺寸轮廓。
- 动作采用 VPet 式“开始 → 循环 → 结束”思路；起飞、巡航和降落各自使用真实姿态帧。
- 不再混合两张像素帧制造补间，避免飞行时出现半透明脏点。
- 睡眠拥有独立的六帧循环与入睡/醒来过渡。
- 加载时自动清除透明边缘上的孤立像素点。

## 备忘录和提醒

右键选择“备忘录与提醒”。可以新增、完成、恢复或删除事项。提醒时间格式：

```text
2026-08-16 09:30
```

数据保存在本机 `notes.json`，不会提交到 GitHub。

## D&D 骰子

右键选择“DND骰子”。支持：

- 快捷骰：d4、d6、d8、d10、d12、d20、d100
- 自定义骰式：`2d6+3`、`d20-1`
- 单次最多投 20 枚骰子
- 自然 20、自然 1和高低结果专属台词
- 当前运行期间的投掷历史
- 成功侦察获得的“情报优势”可用于一次双 d20 取高

## 羁绊养成与 D&D 联动

右键选择“羁绊与养成”查看完整状态：

- **羁绊等级与亲密度**：通过有效互动、讨论冒险和共同专注成长，解锁更高伙伴关系。
- **精力与士气**：决定漆黑当前心情；疲惫时无法侦察，休息可以恢复。
- **侦察等级**：飞行与侦察会积累经验，逐步解锁“锐眼、无声掠影、线索嗅觉、鸦群联络、昨日回声”。
- **D&D 侦察检定**：旧钟楼、鸟网路线和石门监视者拥有不同 DC；结果同时受到侦察等级、亲密度和心情影响。
- **情报优势**：成功侦察可储存最多三次，在骰子窗口消费一次并以优势投掷 d20。
- **防刷机制**：同类互动有每日成长上限，避免把陪伴变成机械刷经验。

心情也会改变碎碎念、飞行意愿和部分互动反馈。旧版本的亲密度与精力会自动迁移到新存档结构。

## 对话气泡

桌面对话改为漆黑主题的深色圆角气泡，带红金描边、心情标题、指向尾巴和逐字显示效果；气泡高度会根据内容自动调整。

## 冒险档案与提问

“冒险档案”内置《鸦影》当前主线、NPC、势力与未解谜团。“向漆黑提问”优先使用在线模型；没有配置 API 时会自动使用本地剧情知识库。

右键选择“API 使用情况”可查看漆黑自身的累计调用次数、成功/失败数、输入与输出 token、本次运行用量和最近请求延迟。统计只保存请求元数据，不保存问题或回答正文；账户账单与组织总用量仍以 OpenAI 官方 Usage 页面为准。本地记录保存在 `api_usage.json`，不会提交到 GitHub。

冒险档案使用可热更新的 `adventure_archive.json`：打开窗口时立即读取，窗口保持打开时每 3 秒检查一次变化。Codex 的“同步漆黑冒险档案”任务会定期读取 ChatGPT 对话“DND继续冒险”，仅在剧情出现新进展时更新当前场景、事实、线索、谜团和下一步。桌宠侦察结果也会追加到同一档案中。

当前内置内容包括：第三章《乌鸦遗产》、旧钟楼、真假令牌、第十二声、上一任乌鸦之死、塞维尔、霍恩、灰指、莉娅/断线会、闭眼组织、守夜人/司门人、鸟网与石门。

### 可选：联网问答

按照[官方 OpenAI 文档](https://developers.openai.com/api/docs/guides/text)，程序通过 Responses API 生成文本。先在系统环境中设置密钥：

```powershell
setx OPENAI_API_KEY "你的API密钥"
```

重新登录 Windows 或重启启动器后生效。密钥不会写入项目文件。可通过 `QIHEI_OPENAI_MODEL` 环境变量覆盖默认模型。

> ChatGPT 订阅与 API 计费是分开的；没有 API Key 时不产生任何费用。

## 设计参考

功能设计参考了 [VPet](https://github.com/LorisYounger/VPet)、[Shimeji-ee](https://github.com/DalekCraft2/Shimeji-Desktop) 和 [Desktop Mate](https://store.steampowered.com/app/3301060/Desktop_Mate/) 的公开功能：随机行为、动作状态机、鼠标互动、专注计时、提醒、状态保存以及低打扰桌面陪伴。

这次重点学习了 VPet 的 `GraphInfo` 动作分类、`Start/Loop/End` 动画阶段、逐帧播放和角色逻辑/资源分离。项目只借鉴公开架构和交互思路；没有复制 VPet 自带角色动画。漆黑仍不加入饥饿值和强制投喂，以免把陪伴变成每日任务。
