# 漆黑桌宠

Windows 桌面上的红眼渡鸦伙伴，性格与故事取自原创 D&D 5e 长篇战役《鸦影》。

## 启动

双击 `启动漆黑.bat`。需要 Python 3 和 Pillow：

```powershell
python -m pip install pillow
```

## 基础互动

- 单击：选中漆黑；按住左键可拖动。
- 双击：打开快捷命令面板；右键选择“出去飞一圈”可飞往桌面上的随机位置。
- 按住左键拖动：移动漆黑，位置会自动保存。
- 右键 → 设置 → 切换外观：像素版和写实版即时切换。
- 可暂停活动、暂停碎碎念、隐藏五分钟，或让漆黑在鼠标附近巡航。
- 右键可让漆黑休息/醒来、查看精力与默契。
- “专注计时”提供 5–90 分钟的桌面专注哨。
- “打开 Geek”会直接启动 `C:\Users\63045\Desktop\LST工作\geek\geek.exe`。
- “搜索本机文件”会在漆黑面板内通过 Everything IPC 返回结果；双击结果即可打开。若 IPC 暂不可用，可一键打开完整 Everything。

右键菜单按用途归为五组：

- **漆黑**：飞行、休息、状态、收藏日记、桌面纪念物、窗口停驻和报时。
- **工作**：快捷命令、专注计时、备忘录、Geek 与内嵌 Everything 搜索。
- **DND 冒险**：羁绊养成、侦察、骰子、先攻战斗、线索图、任务罗盘和冒险档案。
- **问答与 API**：向漆黑提问及 API 使用情况。
- **设置**：外观、活动、鼠标巡航、碎碎念和临时隐藏。

## 动画

- 像素版 v2 使用六帧待机和八帧完整振翅循环；写实版仍可随时切换。
- 像素素材按整数邻近采样缩放，保留硬边和小尺寸轮廓。
- 动作采用 VPet 式“开始 → 循环 → 结束”思路；起飞、巡航和降落各自使用真实姿态帧。
- 不再混合两张像素帧制造补间，避免飞行时出现半透明脏点。
- 睡眠拥有独立的六帧循环与入睡/醒来过渡。
- 新增鼠标追视与歪头、短距离侧跳转身、抖羽和单翼伸展；写实版与像素版均有对应动作。
- “动作导演”统一处理动作优先级与冷却：漆黑会观察停在附近的鼠标，但不会持续追踪或高频抽动。
- 加载时自动清除透明边缘上的孤立像素点。

## 备忘录和提醒

右键选择“备忘录与提醒”。可以新增、完成、恢复或删除事项。既可使用精确时间：

```text
2026-08-16 09:30
```

也可直接写自然语言，例如“半小时后提醒我喝水”“明早八点准备地图”“每周五晚上八点整理冒险笔记”。每天与每周提醒在触发后会自动排到下一次。

数据保存在本机 `notes.json`，不会提交到 GitHub。

## 桌面感知与快捷命令

- 漆黑会偶尔飞到当前窗口的上沿停驻，并在窗口移动时跟随；也可以从右键菜单手动让它停到当前窗口。
- 鼠标静止在头部附近时，漆黑会按羁绊采取亲近或警惕反应；快速追赶会令它闪避，而不是机械地整张贴图抖动。
- 深夜长时间离开电脑会自动入睡，早晨回来会醒来；工作时段减少碎碎念，长时间空闲时会整理羽毛。
- 双击漆黑打开快捷命令面板，可输入“找 文件名”“提醒我……”“骰 2d6+3”“战斗”“冒险”“我的察觉是多少”等命令。
- 每天首次启动会给出简报：首要备忘、当前冒险目标以及昨日漆黑自身的 API 调用摘要。

## 鸦巢控制台与行为导演

右键菜单最上方的“打开鸦巢控制台”是统一入口。界面采用一张动态情报桌：中央鸟巢显示当前目标、羁绊、短期情绪和最近收藏，右侧情报脉络汇总正式档案、跑团记录与漆黑日记。

漆黑现在使用事件导演协调动作与台词。剧情更新、提醒、专注结束、自然 20、自然 1 和 API 故障会按优先级排队，播放“观察—抖羽—伸展—侧跳”等连续动作，不再由多个功能同时抢占贴图。短期情绪包括警觉、好奇、得意、担忧、困惑、安心、专注和振奋，并会逐渐回落到冷静；它会改变自然动作的选择权重。

## 长期记忆

“长期记忆”分为已确认事实、偏好、共同经历与近期事项。对话只会从“叫我……”“我喜欢……”“我不喜欢……”“我正在……”“我信任/怀疑……”这类明确陈述中学习，不会从普通提问推测性格或隐私。所有记忆均保存在本机 `companion_memory.json`，可以手动增加、逐条删除或清空近期事项。

配置在线 API 后，相关记忆和实时冒险档案会作为上下文发送给模型；不相关内容不会被刻意复述。关闭在线 API 时仍使用本地角色卡与剧情知识库。

## 冒险模式与时间线

“开始 / 结束冒险模式”会打开一块置顶的精简 HUD，集中显示当前场景、任务目标、战斗轮次，并提供骰子、战斗和线索入口。冒险模式期间闲聊频率会显著降低，骰子、先攻推进、侦察与档案更新会进入独立跑团日志。

结束冒险后会生成本次记录并进入漆黑日记和共同记忆，但不会自动写入正式剧情事实。“冒险时间线”把正式档案、漆黑日记和跑团日志按来源合并展示，仍保留彼此边界。

## 乌鸦投递袋

投递袋可以接收本机文件或剪贴板文字，并执行以下操作：

- 预览常见文本文件，或直接打开原文件；
- 将材料转成待办；
- 把文字送入提问窗口；
- 经确认后加入本次冒险的“待审材料”；
- 未开启冒险模式时，仅保存为近期事项。

投递内容保存在本机 `drop_bag.json`，不会在未经确认时进入正式 D&D 档案。

## 窗口生态、恢复与诊断

- 支持 Windows 虚拟桌面坐标，可在多显示器范围内巡航。
- 可以沿当前窗口标题栏侧跳，或从屏幕边缘探头；停驻位置继续避开标题栏右侧按钮。
- 只统计窗口类别的访问次数，不保存窗口标题或文档名称。
- 非正常退出后恢复位置、养成状态和进行中的冒险记录。
- 启动时检测可能存在的重复实例并提示，不会强制终止进程。
- “自检与备份”检查动画、档案、API、Everything 与数据源，可将本地存档打包到 `backups/`，并检查 GitHub 上是否有不同版本。

## D&D 骰子

右键选择“DND骰子”。支持：

- 快捷骰：d4、d6、d8、d10、d12、d20、d100
- 自定义骰式：`2d6+3`、`d20-1`
- 单次最多投 20 枚骰子
- 自然 20、自然 1和高低结果专属台词
- 当前运行期间的投掷历史
- 成功侦察获得的“情报优势”可用于一次双 d20 取高

## 羁绊养成与 D&D 联动

右键选择“羁绊与养成”查看完整状态：

- **羁绊等级与亲密度**：通过有效互动、讨论冒险和共同专注成长，解锁更高伙伴关系。
- **精力与士气**：决定漆黑当前心情；疲惫时无法侦察，休息可以恢复。
- **侦察等级**：飞行与侦察会积累经验，逐步解锁“锐眼、无声掠影、线索嗅觉、鸦群联络、昨日回声”。
- **D&D 侦察检定**：旧钟楼、鸟网路线和石门监视者拥有不同 DC；结果同时受到侦察等级、亲密度和心情影响。
- **情报优势**：成功侦察可储存最多三次，在骰子窗口消费一次并以优势投掷 d20。
- **防刷机制**：同类互动有每日成长上限，避免把陪伴变成机械刷经验。

心情也会改变碎碎念、飞行意愿和部分互动反馈。旧版本的亲密度与精力会自动迁移到新存档结构。

羁绊还会逐步改变性格：低羁绊时更克制、与鼠标保持距离；熟悉后会主动靠近、允许整理羽毛，并用更像老搭档的语气提醒你。它不会因为数值变化突然换成另一个角色。

## 对话气泡

桌面对话改为漆黑主题的深色圆角气泡，带红金描边、心情标题、指向尾巴和逐字显示效果；气泡高度会根据内容自动调整。

## 冒险档案与提问

“冒险档案”内置《鸦影》当前主线、NPC、势力与未解谜团。“向漆黑提问”优先使用在线模型；没有配置 API 时会自动使用本地剧情知识库。

右键选择“API 使用情况”可查看漆黑自身的累计调用次数、成功/失败数、输入与输出 token、本次运行用量和最近请求延迟。统计只保存请求元数据，不保存问题或回答正文；账户账单与组织总用量仍以 OpenAI 官方 Usage 页面为准。本地记录保存在 `api_usage.json`，不会提交到 GitHub。

冒险档案使用可热更新的 `adventure_archive.json`：打开窗口时立即读取，窗口保持打开时每 3 秒检查一次变化。Codex 的“同步漆黑冒险档案”任务会定期读取 ChatGPT 对话“DND继续冒险”，仅在剧情出现新进展时更新当前场景、事实、线索、谜团和下一步。桌宠侦察结果也会追加到同一档案中。

“冒险任务罗盘”会把实时档案压缩为一个首要目标，并同时显示当前位置、风险、已知抓手、关键未知和漆黑的行动建议。它不会生成新剧情，只使用档案中已经同步的内容。

“先攻与战斗”保存参战者的先攻、生命与状态，可推进回合、自动进入下一轮并快速调整 HP。“线索关系图”只绘制档案中已经确认的事实、活跃线索、未解谜团和建议行动；点击节点可以查看原文。角色卡数据保存在 `character_sheet.json`，快捷命令和提问窗口可本地回答已确认技能数值，不会擅自补全未知属性。档案被外部同步更新时，漆黑只发出无剧透提示。

## 收藏与漆黑日记

右键选择“漆黑 → 收藏与日记”。巡空、侦察、专注和档案联动会留下少量纪念物与漆黑口吻的日记。数据单独保存在本机 `raven_memories.json`；它记录桌宠侧的共同经历，不会写入或修改正式 D&D 剧情事实。

当前内置内容包括：第三章《乌鸦遗产》、旧钟楼、真假令牌、第十二声、上一任乌鸦之死、塞维尔、霍恩、灰指、莉娅/断线会、闭眼组织、守夜人/司门人、鸟网与石门。

“显示桌面纪念物”会在漆黑旁边展开最近四件收藏；点击图标可阅读来历。正式剧情事实仍只由冒险档案维护，桌宠日记和纪念物不会反向改写剧情。

## Everything 内嵌搜索

项目随附纯 Python IPC 客户端 wheel。首次查询时，漆黑会按需启动名为 `Qihei` 的普通权限实例，以只读方式加载现有 `Everything.db`，再通过 IPC 取回结果；不会安装系统服务、添加启动项、扫描磁盘或改变原 Everything 的管理员配置。数据库或 IPC 暂不可用时，面板仍可一键打开完整 Everything。

### 可选：联网问答

按照[官方 OpenAI 文档](https://developers.openai.com/api/docs/guides/text)，程序通过 Responses API 生成文本。先在系统环境中设置密钥：

```powershell
setx OPENAI_API_KEY "你的API密钥"
```

重新登录 Windows 或重启启动器后生效。密钥不会写入项目文件。可通过 `QIHEI_OPENAI_MODEL` 环境变量覆盖默认模型。

> ChatGPT 订阅与 API 计费是分开的；没有 API Key 时不产生任何费用。

## 设计参考

功能设计参考了 [VPet](https://github.com/LorisYounger/VPet)、[Shimeji-ee](https://github.com/DalekCraft2/Shimeji-Desktop) 和 [Desktop Mate](https://store.steampowered.com/app/3301060/Desktop_Mate/) 的公开功能：随机行为、动作状态机、鼠标互动、专注计时、提醒、状态保存以及低打扰桌面陪伴。

这次重点学习了 VPet 的 `GraphInfo` 动作分类、`Start/Loop/End` 动画阶段、逐帧播放和角色逻辑/资源分离。项目只借鉴公开架构和交互思路；没有复制 VPet 自带角色动画。漆黑仍不加入饥饿值和强制投喂，以免把陪伴变成每日任务。
